# Xcode Inspired — VS Code

Includes Xcode Inspired Light and Xcode Inspired Dark, based on screenshots of Xcode's SwiftUI editor.

## Preview
Open this folder in VS Code, press F5, then choose **Preferences: Color Theme** → **Xcode Inspired Light** or **Xcode Inspired Dark**.

## Install permanently
With Node.js installed, run `npx --yes @vscode/vsce package` inside this folder. Then in VS Code choose **Extensions: Install from VSIX...** and select the generated `.vsix` file.

Colors are approximations; Swift token highlighting may depend on the installed Swift extension.
